# betenya.dev

Персональный сайт-портфолио. Next.js (App Router, SSG), TypeScript, Tailwind CSS. Два языка (`/ru`, `/en`), тёмная/светлая тема, деплой на Vercel.

## Запуск локально

Нужны Node.js LTS (см. `.nvmrc`) и pnpm.

```bash
pnpm install
pnpm dev        # http://localhost:3000 (редирект на /ru)
```

Прочие команды:

```bash
pnpm build      # прод-сборка (все страницы генерируются статически)
pnpm start      # запустить собранную версию
pnpm lint       # ESLint
pnpm format     # Prettier
```

## Где редактировать контент

Весь контент лежит в `src/content/` — компоненты трогать не нужно. Каждая строка задаётся для двух языков: `{ ru: '...', en: '...' }`. Места, требующие уточнения, помечены `// TODO`.

| Файл                        | Что внутри                                                                               |
| --------------------------- | ---------------------------------------------------------------------------------------- |
| `src/content/profile.ts`    | Имя, роль, фраза в hero, блок статуса, «Обо мне», контакты, метаописание                 |
| `src/content/experience.ts` | Таймлайн опыта и учёбы (периоды в формате `ГГГГ-ММ`, `end: null` = «по настоящее время») |
| `src/content/projects.ts`   | Проекты: карточки и подробные страницы `/projects/[slug]`                                |
| `src/content/skills.ts`     | Навыки по категориям (`learning: true` → бейдж «изучаю»)                                 |
| `src/content/ui.ts`         | Подписи интерфейса: навигация, кнопки, статусы                                           |

## Как добавить проект

1. В `src/content/projects.ts` добавь объект в массив `projects` — карточки выводятся гридом по 3 в строку:
   - `slug` — сегмент URL (`/ru/projects/<slug>`), страница сгенерируется автоматически через `generateStaticParams`;
   - `accent` (опционально) — цветовое выделение особенного проекта: `gold` — главный проект (золотая карточка на всю ширину первой строкой, может быть только один), `blue` | `emerald` | `red` — цветной оттенок;
   - `status` — `released` | `in-dev` | `done`;
   - `links` — массив ссылок (`site`, `github`, `appstore`, `googleplay`, `telegram`, `marketplace`).
2. Больше ничего делать не нужно: sitemap, OG-картинка и hreflang подхватятся сами.

## Устройство

- `src/app/[locale]/` — страницы для `ru`/`en`; корень `/` редиректится на `/ru` (см. `next.config.ts`).
- Тема: системная по умолчанию, переключатель светлая/тёмная/системная; инлайн-скрипт в `layout.tsx` ставит класс до первой отрисовки — мигания нет. Выбор хранится в `localStorage`.
- Анимации — только CSS; при `prefers-reduced-motion` и без JS контент показывается сразу.
- OG-картинки генерируются через `next/og` (`opengraph-image.tsx`); текст в них — латиницей, т.к. встроенный шрифт не содержит кириллицы.
- SEO: `sitemap.ts`, `robots.ts`, hreflang `ru`/`en`/`x-default`, `metadataBase = https://betenya.dev`.

## Деплой

Обычный Next.js-проект для Vercel: импортируй репозиторий, фреймворк определится сам, привяжи домен `betenya.dev`. Переменные окружения не нужны.
